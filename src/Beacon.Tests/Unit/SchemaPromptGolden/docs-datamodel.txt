# Full Schema Metadata

## Data Source: core
### sales.order_lines
Description: One line per ordered item
Columns:
  - order_id integer PK NOT NULL FK→sales.orders.id — Order the line belongs to
  - tenant_id integer PK NOT NULL FK→sales.orders.tenant_id
  - line_no smallint PK NOT NULL
  - sku varchar NOT NULL
  - status text NOT NULL — Line state
  - amount numeric(12,2)
  - contact_email varchar — Buyer contact
  - notes text
Indexes:
  - ix_order_lines_sku (sku)
  - ux_order_lines_key (order_id, tenant_id, line_no) UNIQUE
Enum/Status Values:
  - status: [open (1,200 rows), shipped (30,000 rows), returned (7 rows)]
