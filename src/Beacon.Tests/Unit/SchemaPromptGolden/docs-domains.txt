# Tables and Relationships

## Data Source: core
### sales.order_lines
Description: One line per ordered item
  - order_id (integer) [PK] FK→sales.orders.id
  - tenant_id (integer) [PK] FK→sales.orders.tenant_id
  - line_no (smallint) [PK]
  Columns: order_id, tenant_id, line_no, sku, status, amount, contact_email, notes
  - status values: [open, shipped, returned]
### sales.orders
  - id (bigint) [PK]
  - tenant_id (integer) [PK]
  - customer_id (integer) FK→crm.customers.id
  Columns: id, tenant_id, customer_id, legacy_ref, placed_at
